# HTML & CSS Projects Collection

This repository contains **5 beginner-to-intermediate HTML & CSS projects** that showcase different layouts, styles, and design techniques.  
Perfect for practice, learning, or inspiration.

## 📂 Projects in This Repository

1. **Portfolio Website**  
   - A personal portfolio template with sections for About, Skills, Projects, and Contact.  
   - **Features:** Responsive design, smooth scrolling, clean UI.

2. **Landing Page**  
   - A single-page landing website for a fictional product/service.  
   - **Features:** Hero section, call-to-action buttons, modern typography.

3. **Blog Template**  
   - A static blog layout with homepage, blog posts, and sidebar.  
   - **Features:** Grid-based layout, semantic HTML, custom styling.

4. **Restaurant Website**  
   - A restaurant homepage with menu, gallery, and contact form sections.  
   - **Features:** Image gallery, styled navigation bar, responsive grid.

5. **E-commerce Product Page**  
   - A single product showcase page for an online shop.  
   - **Features:** Product details section, pricing, and customer reviews.
